# 💻 Laptop Market Analysis Dashboard | Power BI

## 📖 Overview
The **Laptop Market Analysis Dashboard** is an interactive Business Intelligence project developed using **Power BI** to analyze laptop market data. It provides valuable insights into pricing, brand performance, customer ratings, RAM distribution, and performance tiers through dynamic visualizations and KPI cards.

This dashboard enables users to compare laptop brands, identify pricing trends, and evaluate product performance using interactive filters and business-focused metrics.

---

## 🎯 Project Objectives
- Analyze laptop pricing across different brands.
- Compare brand performance based on customer ratings.
- Categorize laptops by price range and performance tier.
- Evaluate RAM distribution across performance categories.
- Build an interactive dashboard for data-driven decision making.

---

## 📊 Dashboard Features

- 📌 Highest & Lowest Laptop Price KPIs
- 📌 Brand-wise Laptop Value Analysis
- 📌 Highest Price by Company & Performance Tier
- 📌 Average RAM by Performance Tier
- 📌 Customer Ratings Analysis by Brand
- 📌 Laptop Distribution by Price Category
- 📌 Popularity Category Slicer
- 📌 Company-wise Number of Ratings Summary

## 📂 Dataset Attributes

The dataset contains laptop-related information, including:

- Company
- Laptop Name
- Price
- RAM
- Storage
- Processor
- Operating System
- Star Rating
- Number of Ratings
- Number of Reviews
- Warranty
- Performance Tier
- Price Category
- Popularity Category

---

## 📈 Key Insights

- Lenovo, ASUS, and HP contribute significantly to the overall laptop market value.
- High-performance laptops have the highest average RAM configuration.
- Premium laptops account for a smaller share of the market compared to mid-range devices.
- Customer ratings and popularity vary significantly across brands.
- Price categories help identify budget, mid-range, premium, and luxury laptop segments.
